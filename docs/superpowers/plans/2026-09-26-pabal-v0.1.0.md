# pabal v0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `pabal` v0.1.0, a library crate that parses Claude Code and Codex hook payloads, gives typed views of events and tool calls, and builds each harness's hook response JSON.

**Architecture:** Zero-sized harness types implement a sealed `Harness` trait carrying the harness's event and view types. `Payload<H>` wraps the raw JSON. A `Fields` trait holds the harness-independent accessors, and `AnyPayload` delegates it with ambassador for runtime harness choice. Response methods are traits implemented only on the (harness, event) view types that support them, so an unsupported response fails to compile.

**Tech Stack:** Rust edition 2024, MSRV 1.85; `serde_json`, `strum`, `ambassador`, `thiserror`, optional `clap`; dev: `jsonschema`, `cargo-nextest`; `bun` for the drift script; GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-26-pabal-design.md`. Read it before any task. Where this plan and the spec disagree, the spec wins; report the disagreement.

## Review Focus

1. **Empty and wrong-typed fields.** Someone sends `"session_id": ""`, `"session_id": 7`, `"cwd": null` or `"tool_input": "ls"`. They expect `None` or `Tool::Other`, never a panic and never `Some("")`. Pinned in Task 3 (`blank_and_wrong_typed_fields_are_none`) and Task 4 (`a_string_tool_input_is_other`).
2. **Cursor running a Claude-configured hook.** Cursor runs hooks from `~/.claude/settings.json` by default. A payload like `{"hook_event_name":"SessionStart","cursor_version":"1.7.0","model":"claude-4.5-sonnet"}` should infer as Claude Code, not Codex, and parse to `ClaudeCodeEvent::SessionStart`. Pinned in Task 1 (`cursor_run_claude_hooks_infer_as_claude_code`) and Task 7 (the `claude-code/SessionStart/cursor-run.json` fixture).
3. **MCP names containing `__`.** `mcp__srv__do__thing` should give server `srv` and tool `do__thing`. When Claude's `mcp_server.name` is `my__srv`, it should give server `my__srv` and tool `do_thing`. Pinned in Task 4.
4. **Response text with quotes, newlines and non-ASCII.** A deny reason containing `"`, `\n` and `ü` must round-trip through `serde_json::from_str(&response.to_string())` unchanged. Pinned in Task 6 (`reasons_survive_json_escaping`).
5. **Windows paths.** A path like `C:\repo\a.rs` in `tool_input.file_path` or `cwd` should come back verbatim, with no normalization. Pinned in Task 4 (`windows_paths_are_verbatim`).
